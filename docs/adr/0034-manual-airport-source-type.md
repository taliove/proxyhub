# ADR 0034: 手动机场来源类型与 url 空串

## 状态

提议

## 上下文

部分机场禁止外网访问/拉取其订阅地址(只允许面板内查看导出),现有"添加机场填 URL"无法接入;用户只能手动导出约 200 条分享链接。既有"一键导入"仅支持单节点且落点是自建节点(FailBack 语义),批量与语义双双错位(见 spec-manual-airport-import)。

关键权衡:

1. **手动机场如何标记**:`airports.url TEXT NOT NULL` 无来源类型标记。候选:允许 url NULL、哨兵值(如 `manual://`)、独立 `source_type` 列 + url 空串。NULL 会让全部读方(列表/诊断/QR/刷新)增加空值分支;哨兵值把类型信息编码进数据列,查询与校验都要解析;独立列是显式模型,迁移幂等(`addColumnIfMissing`,默认 'url' 覆盖全部历史行)。
2. **粘贴导入的执行形态**:粘贴内容含节点凭证。做成 job kind 会把内容落进 `params_json`(任务中心 API 原样回显),等于凭证明文持久化——与订阅 URL 不落 params(issue 0025)同一红线。
3. **全量刷新与手动机场的关系**:全量刷新成功路径的 `MergePool` 会把"旧池有、新拉取集没有"的机场节点标 stale;手动机场永不出现在拉取集内,直接跳过拉取会让其节点整批 stale。
4. **机场节点清空是否覆盖手动机场**:清空的设计语义是"下轮刷新冲回"的重置起点;手动机场无 URL 可拉,清空后永不回来,语义不成立。

## 决策

1. **独立 `source_type` 列,手动机场 url 存空串**。`airports.source_type` ∈ {`url`(默认), `manual`},`addColumnIfMissing` 内联幂等补列,历史行全部落 'url';不引入 NULL 与哨兵值。来源类型创建时二选一,创建后不可变(编辑不改类型)。
2. **粘贴导入走同步 HTTP 端点,非任务**(`POST /api/airports/{id}/import`):内容不落库、不进日志、不进 jobs params;系统不保存粘贴原文。互斥复用刷新的 `refreshStartMu` 临界区(与全量/同机场刷新、同机场机场测试互斥,冲突 409);入池复用单机场 upsert 口径(`poolops.UpsertAirportNodes`,不跑健康检查)。体积上限 1MiB(413)。
3. **per-source 合并**:全量刷新成功路径与取消路径共用同一 per-source 合并手法——stale 扫描集 = 成功拉取来源 ∪ 旧池中"不再现存启用"的来源(机场已删除/被禁用/已改名的旧名,属合法消失,照旧下架);保留集 = 本轮未成功拉取但仍现存启用的机场(手动跳过/拉取失败/取消未启动,本轮无数据 ≠ 节点消失)。合并尾部按 NodeKey 去重(新拉取集优先),防跨来源同 server:port 双份。定时/全量刷新在拉取列表层跳过手动机场,告警(checkAlerts)随之不见手动机场。
4. **机场节点清空豁免手动机场节点**(内存池与 DB 双清同步豁免,DB 侧经同事务 SQL 子查询判定)。手动机场节点可用性不参与周期健康检查(不在拉取集内),靠检测状态保留与手动检测维持。
5. **用量信息只展示不联动**:拉取型每次拉取从响应头捕获覆盖(`subscription-userinfo` / `profile-web-page-url`;头缺失保留既有值);手动型手填,用户填"剩余",存储统一为 upload/download/total(已用计 download,上行计 0)。不发告警、不自动停用(告警联动留待拆分暂存)。

## 理由

- 独立列 + 空串是对全部既有读方影响面最小的显式模型:url 列语义不变(拉取型恒非空),空值分支集中在 `source_type == 'manual'` 一处判断。
- 同步导入不是"图省事":凭证红线排除了任务化,而导入本身是秒级的内存解析 + 单机场 upsert,同步响应还能直接带回逐行失败明细(任务化要再造一条结果查询链)。
- per-source 合并把"未拉取 ≠ 消失"从取消路径的特例升格为统一语义,同时修复了拉取失败机场节点被误标 stale 的隐患(与"全量失败保留池"的既有防线同向)。
- 清空豁免是语义自洽:清空的价值依赖"能冲回来",手动机场不满足这个前提。

## 后果

- 手动机场行内按钮叫"重新粘贴"而非"刷新"(术语纪律);`POST /airports/{id}/refresh` 对手动机场返 400。
- 机场测试对手动机场可用:诊断段标 `manual_source`(N/A),评分走 URL 不可达的权重重归一(现成语义),池空 failed 文案引导粘贴导入。
- 模型与交互细节见 [design-airports](../design-airports.md);术语见 CONTEXT.md「手动机场」「用量信息」。
