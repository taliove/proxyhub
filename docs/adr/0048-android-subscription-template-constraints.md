# 0048: Android 客户端订阅模板约束与订阅链接重置

- 状态: accepted
- 日期: 2026-08-13
- 关联: spec #114(故障定位与方案); ticket #115/#116/#117/#118/#119; ADR 0033(pull-guard,URL 泄露威胁面); ADR 0045(订阅地址挂根命名空间); SECURITY.md 失陷响应清单

## 背景

2026-08 用户报告: ProxyHub 生成的订阅地址在 iOS/macOS/Windows 客户端全部正常, 唯独 Android(FLClash, mihomo 内核)上所有节点延迟测试全部超时, 同机同客户端下机场原版订阅工作正常. 定位出两条互相独立的根因:

1. **默认模板 dns 段对 Android 致命**. 桌面/iOS 客户端(Clash Verge/Shadowrocket 等)普遍覆写或忽略订阅内的 dns 段, Android 客户端原样使用——因此模板 dns 段必须在 Android 直连环境下自洽. 旧配置中 `fallback` 指向境外 DoT(`tls://1.1.1.1:853`), 境内直连永不可达, mihomo 的 fallback-filter 会把全部境外域名(含自建节点域名)解析整体拖死; `dns.listen: 127.0.0.1:53` 在 Android 无 root 环境绑不了 <1024 端口; 且缺少 `proxy-server-nameserver` 独立解析通道.
2. **上游机场导入丢 hosts**. Clash YAML 解析器原本只提取 `proxies` 列表, 上游用 `hosts:` 段把被 DNS 污染的节点域名改指到可解析别名的机制被整体丢弃, 重新导出的节点 server 裸域名在境内无法解析.

同批交付的订阅链接重置: 此前订阅地址的 path+token 创建后不可变, 唯一的换链接手段是删除端点重建, 端点上的筛选/精选/模板绑定/地域白名单全部丢失. ADR 0033 早把"URL 泄露被蹭用"列为威胁面, 但一直没有对应的响应手段.

## 决策

### 模板 DNS 基线(Android 三约束, 境内外单一基线)

任何进默认模板的 dns 配置必须满足三条硬约束:

1. **监听端口禁 <1024**(Android 无 root 绑不了特权端口), 且只绑回环——当前取 `127.0.0.1:1053`.
2. **禁境外 DoT/DoH 作 fallback 或主 nameserver**(境内直连不可达; 一条死掉的 fallback 会拖死全部境外域名解析). 默认模板**不再声明 fallback**.
3. **必备 `default-nameserver` 与 `proxy-server-nameserver`**(纯 UDP 国内 DNS), 节点域名解析走独立通道, 与主 nameserver 状态隔离.

用户群境内外混布, 但**采用单一基线**: 国内 DoH 全球可达, 境外用户只是 CDN 亲和性略差, 可用性不受影响; 任何境外 DNS 对境内用户则是"通/不通"的二元问题. 不做境内/境外双模板, 境外优化变体等真实需求出现再议(模板库多模板能力留有扩展位). 另补 `use-hosts: true`/`use-system-hosts: true`(为 hosts 保真铺路)/扩充 `fake-ip-filter` 通行清单/顶层 `unified-delay: true`.

### 上游 hosts 保真

Clash YAML 解析器捕获上游顶层 `hosts:` 映射(拉取型机场与手动粘贴导入共用同一解析器, 一处改动两路生效), 覆盖落库到机场记录(空 = 显式清空), 渲染订阅时按端点可见节点池所涉来源合并进输出 `hosts:` 段. 合并优先级三层固定: **来源名字典序后并者覆盖 < 多来源合并结果 < 模板自带 hosts**(模板是运营者显式意图, 永远最高). 不做服务端代解析(境内服务器解析被污染域名无意义), 不做污染自动嗅探.

信任假设记录于此: 上游 hosts 原样进公开订阅输出, 被投毒的上游可以给该订阅全部客户端钉扎任意域名解析; 机场本就控制节点服务器, 信任域未实质扩大, 且模板同键覆盖给了运营者最终否决权.

### 订阅链接重置与宽限期

- 端点级"重置链接": 原位重新生成 path(16 hex)+token(32 hex), 端点全部配置保留; endpoints 表新增 `prev_path`/`prev_token`/`grace_expires_at`.
- 旧链接**默认 3 天宽限**, 宽限内照常下发(内容与新链接一致), 可手动延长每次 +3 天(仅存活期, 自当前到期时间累加); 宽限过期不可复活; 再次重置覆盖 prev 槽位, 只保留一代宽限不叠加.
- 404 无差别语义不破: 未知 path/prev 未命中/token 不匹配/宽限过期/端点禁用五个出口对外完全一致, 不暴露端点与宽限的存在; 差异只留在内部 pull_logs(宽限命中记独立 `grace_ok` 状态, 供管理员观察蹭用迁移).
- 入口: 用户个人中心自助 + 管理员在用户管理代为重置(同一 store 方法, 前端"全部重置"逐条调用, 服务端无批量端点).

## 后果

- Android 客户端拿到的默认模板开箱可用; iOS/macOS/Windows 与境外用户无回归.
- 上游 hosts 随订阅自动透传, 被污染机场域名在任何客户端可解析; 模板作者对合并结果有最终否决权.
- 链接泄露的响应手段从"删建丢配置"变为"一键重置 + 3 天迁移窗口"; SECURITY.md 失陷响应清单同步增补.
- 已绑定自定义模板或用户级默认模板的用户**不会**自动获得新内嵌模板(模板回退链), 需要按发布说明手动同步.
