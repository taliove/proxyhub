# ADR 0004: 机场刷新可关闭,纯手动触发

## 状态

已接受

## 上下文

部分机场的订阅 URL 需先在机场面板手动开权限才可拉取,定时自动拉多数情况会失败或无意义。节点池仅存在内存中,不落库(见 ADR 0003 只持久化配置与统计,不含运行时节点池)。

## 决策

在系统设置增加"定时刷新"开关(默认**开**,保持现状)。关闭后:

- 启动刷新与周期性刷新**都不执行**
- 只有**手动刷新**能触发一轮聚合

## 后果

关闭定时后**重启服务器 → 内存节点池为空 → 订阅地址返回 503**,直到手动刷新一次。

这是**有意为之**(选实现简单,不做节点池持久化),不是 bug——请勿当作缺陷去"修复"启动自动拉取。将来若嫌重启后需手动刷新麻烦,正确做法是把最后一轮聚合的节点池落库、启动时加载(独立工作,非本 ADR 范围)。
