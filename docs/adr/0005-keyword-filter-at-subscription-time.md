# ADR 0005: 关键词过滤在订阅生成时生效(两阶段过滤)

## 状态

已接受

## 上下文

机场订阅常混入"假节点"(名称如"剩余流量""到期时间""官网""进群"),需按名称关键词剔除。系统已有**结构性过滤**(去重、每地区限额、延迟阈值)在**聚合时**对节点池生效。

## 决策

新增**关键词黑名单**(子串匹配、不区分大小写,在系统设置里配置),在 `/sub` **生成订阅那一刻**对节点池过滤,而非聚合时。

## 理由

- 改关键词**即时对下一次订阅生效,无需手动刷新一轮**——契合 ADR 0004 的纯手动刷新模式
- 假节点数量少、且多半过不了健康检查,聚合时提前剔除省下的开销不值当

## 后果

过滤逻辑**分两个阶段**:结构性过滤 @ 聚合(去重/限额/延迟),表现性过滤 @ 订阅(关键词黑名单)。读者请勿把关键词过滤"顺手挪回"聚合层——那会破坏即时生效的语义。订阅地址的"预览"功能必须应用同一份关键词过滤,才能所见即所得。
