# Triage 标签

skill 以五个标准 triage 角色说话。本文件把这些角色映射到本仓库 issue 跟踪器实际使用的标签字符串。

| mattpocock/skills 的标签 | 本仓库跟踪器的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这个 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完备,可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某个角色时(如"打上 AFK-ready triage 标签"),使用上表对应的标签字符串。

右列可按实际使用的词汇编辑。
